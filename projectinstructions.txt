I want to create a bot that searches the web for jobs for me, specifically on LinkedIn.
When it starts up, it will prompt the user for their login and password for LinkedIn, and then asks them what keywords it would like searched separated by a comma.
It will also prompt you for job location preferences separated by a comma.
The findings will be stored in a .csv file where the rows will be each job, and the column will be the job title, the job location, the job description, the qualifications, and the salary.
I want to have a separate file for internships for recent master's graduates and for entry level jobs.
